# Shared Contracts

## Propósito

Este directorio alojará los **contratos compartidos** entre:

- **Frontend React** (nuevo)
- **Backend temporal en GAS** (actual)

El objetivo es **desacoplar** frontend y backend mediante definiciones explícitas de:

- modelos de datos (DTOs)
- requests/responses
- errores esperados y códigos
- convenciones de versionado de endpoints (cuando aplique)

## Futuras definiciones de APIs

En fases posteriores se incorporarán aquí las definiciones de API necesarias para:

- login
- menú principal
- módulos funcionales migrados incrementalmente

## Nota importante

En esta fase inicial **no se definen aún contratos formales**; solo se prepara el espacio para estabilizarlos cuando comiencen las integraciones React ↔ GAS.
