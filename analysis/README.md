# Analysis

## Propósito

Este directorio centraliza **análisis arquitectónicos** y documentación técnica de soporte para la migración, incluyendo:

- auditorías del legacy (inventarios de pantallas, flujos, módulos)
- dependencias (técnicas y funcionales)
- puntos de integración legacy ↔ GAS ↔ React
- decisiones y trade-offs documentados (cuando existan)

## Documentación temporal

La información aquí puede ser **iterativa y temporal** durante fases tempranas; se consolidará en `docs/` y en `shared-contracts/` cuando los contratos y la arquitectura se estabilicen.
